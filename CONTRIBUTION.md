## How to Contribute

We welcome suggestions, improvements, and contributions that can make this project more informative and useful.

### 1. Reporting Bugs and Suggesting Features

- Check the "Issues" (https://github.com/rheachoy/COVID19-STUDY/issues) tab to see whether the issue has already been reported.
- If it has not, open a new issue describing the bug, suggestion, or feature request clearly.
- Include relevant details or examples to help others understand the issue.
